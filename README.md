# Student Academic Performance Prediction

## 1. Project Overview
Student Academic Performance Prediction is a machine learning project
that predicts students' final marks using their academic information.

The project uses Linear Regression, a supervised machine learning algorithm.

## 2. Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Matplotlib
- Machine Learning

## 3. Algorithm
Linear Regression

## 4. Dataset
UCI Student Performance Dataset.

Dataset: Student Mathematics Performance (student-mat.csv)

## 5. Input Features
- Study Time
- Previous Failures
- Absences
- First Period Marks (G1)
- Second Period Marks (G2)

## 6. Output
The system predicts the student's final marks (G3) out of 20.

## 7. Project Files
- app.py: Main Streamlit application.
- model_utils.py: Data loading and machine learning functions.
- train_model.py: Model training program.
- requirements.txt: Required Python libraries.
- README.md: Project information.

## 8. Installation

Install the required libraries:

pip install -r requirements.txt

## 9. Run the Project

Run the following command:

streamlit run app.py

## 10. Project Objective
The main objective is to predict student academic performance
using machine learning and help understand the relationship
between academic factors and final marks.
